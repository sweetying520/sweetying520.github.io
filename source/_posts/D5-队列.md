## 前言

队列是一种基于 FIFO（先进先出）的数据结构，是一种只能在一端进行插入，在另一端进行删除操作的特殊线性表。它按照先进先出的原则存储数据，先进入的数据，在读取数据时会先被读出来

## 一、队列

我们称数据进入到队列的动作称为**入队**，数据从队列中出去的动作为**出队**，如下图：


![image-20221212203805902.png](https://raw.githubusercontent.com/sweetying520/picgo/master/img/202309281558550.png)

### 1.1、 API 设计

| 类名       | `Queue<T>`                                                   |
| ---------- | ------------------------------------------------------------ |
| 构造方法   | Queue() ：创建 Queue 对象                                    |
| 成员方法   | 1、public boolean isEmpty() ：判断队列是否为空<br>2、public int size() ：获取队列中元素的个数<br>3、public T enQueue(T t) ：入队<br>4、public void deQueue() ：出队 |
| 成员变量   | 1、private Node head ：记录头节点<br>2、private int N ：当前队列的元素个数<br>3、public Node last ：记录尾节点<br> |
| 成员内部类 | private class Node ：节点类                                  |

### 1.2、队列代码实现

```java
public class Queue<T>{

    private Node head;
    private Node last;
    private int N;


    private class Node{
        public T item;
        public Node next;

        public Node(T item, Node next) {
            this.item = item;
            this.next = next;
        }
    }

    public Queue(){
        head = new Node(null, null);
        last = null;
        N = 0;
    }

    public int size(){
        return N;
    }

    public boolean isEmpty(){
        return N == 0;
    }

    public void enQueue(T item){
        //当前尾节点为null
        if(last == null){
            last = new Node(item, null);
            head.next = last;
        }else {
            Node oldLast = last;
            Node newNode = new Node(item, null);
            oldLast.next = newNode;
            last = newNode;
        }
        N++;
    }

    public T deQueue(){
        Node temp = head.next;
        if(temp == null) return null;
        head.next = temp.next;
        N--;
        //因为出队列其实是在删除元素，因此如果删除完了，需要重置 last 为null
        if(isEmpty()){
            last = null;
        }
        return temp.item;
    }
}
```

### 1.3、队列遍历

我们也让 Queue 支持增强 for 循环：

1、让 Queue 实现 Iterable 接口，重写 iterator 接口

2、在 Queue 内部提供一个内部类 QIterator，实现 Iterator 接口，重写 hasNext() 方法和 next() 方法

具体实现：

```java
public class Queue<T> implements Iterable<T>{

    private Node head;
    private Node last;
    private int N;


    private class Node{
        public T item;
        public Node next;

        public Node(T item, Node next) {
            this.item = item;
            this.next = next;
        }
    }

    public Queue(){
        head = new Node(null, null);
        last = null;
        N = 0;
    }

    public int size(){
        return N;
    }

    public boolean isEmpty(){
        return N == 0;
    }

    public void enQueue(T item){
        //当前尾节点为null
        if(last == null){
            last = new Node(item, null);
            head.next = last;
        }else {
            Node oldLast = last;
            Node newNode = new Node(item, null);
            oldLast.next = newNode;
            last = newNode;
        }
        N++;
    }

    public T deQueue(){
        Node temp = head.next;
        if(temp == null) return null;
        head.next = temp.next;
        N--;
        //因为出队列其实是在删除元素，因此如果删除完了，需要重置 last 为null
        if(isEmpty()){
            last = null;
        }
        return temp.item;
    }

    //================================== 新增部分代码 start =================================
    @NonNull
    @Override
    public Iterator<T> iterator() {
        return new QIterator();
    }

    private class QIterator implements Iterator<T>{

        private Node temp;

        public QIterator() {
            temp = head;
        }

        @Override
        public boolean hasNext() {
            return temp.next != null;
        }

        @Override
        public T next() {
            temp = temp.next;
            return temp.item;
        }
    }
    //================================== 新增部分代码 end =================================
}
```

### 1.4、队列测试

```java
public class QueueTest {

    public static void main(String[] args) {
        Queue<Integer> integerQueue = new Queue<>();
      	//一、入队
        integerQueue.enQueue(1);
        integerQueue.enQueue(2);
        integerQueue.enQueue(3);
        integerQueue.enQueue(4);
			
      	//二、增强 for 循环
        for (Integer integer : integerQueue) {
            System.out.println(integer);
            //1
            //2
            //3
            //4
        }

      	//三、出队
        Integer integer = integerQueue.deQueue();
        System.out.println(integer);//1
				
      	//四、队列中剩余的元素个数
        System.out.println(integerQueue.size());//3
    }
}
```
